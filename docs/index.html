What it does

Every piece is exact.

A skill is a written method for one kind of work: when to use it, what it covers, what it hands on, and the checks that prove it is done.

  1. i

    The right method, without asking.

    A router picks the skills a request needs before Claude starts.

  2. ii

    Done means proven.

    Hook files block dangerous commands, scan for secrets and refuse a “done” without proof.

  3. iii

    Designs held to rules.

    The design brain checks every design against 62 laws and keeps 52 ready ops for glass, metal, water, sky and light.

  4. iv

    Keys kept out of sight.

    The Stryx Tools mod keeps your keys in a Vault. They are used by name and never shown.

The tree

Eight groups, one band of light each.

From the red of planning to the violet of the modes. Each leaf is one skill, 94 in all. Point at a group to light its branch.

  1. Book one of eight

    Before the work: what to build, how, in what order, and who does it. First book: stryx:ai-power

  2. Book two of eight

    Finding what is wrong, proving what is right, and making code better. First book: stryx:debug

  3. Book three of eight

    Everything you see and hear: screens, pictures, 3D, video, sound. First book: stryx:design

  4. Book four of eight

    One book per programming language or app platform. First book: stryx:electron

  5. Book five of eight

    Websites, online services, databases and the network. First book: stryx:integrations

  6. Book six of eight

    Words for people: messages, docs, proposals, announcements. First book: stryx:writing

  7. Book seven of eight

    Keeping the work moving and remembered: git, handoffs, lessons, setup, tools. First book: stryx:devops

  8. Book eight of eight

    The words you type to steer Claude itself. First book: stryx:modes

Hooks and proof

Forty-six hooks act on their own.

A hook runs by itself at a fixed moment: before Claude starts, before a command, after an edit, before Claude says done. Four of them, at their moments:

  1. Before Claude starts

    A router

    picks the skills a request needs.

  2. Before a command

    A guard

    blocks dangerous commands.

  3. After an edit

    A design detector

    checks the page after every UI edit.

  4. Before Claude says done

    A stop judge

    refuses a “done” that has no proof.

Three more watch the whole turn: a secret scanner for keys and passwords, a test check that asks whether a test exists for the change, and a logbook that writes down every failure.

Install

One command. The whole set.

  1. Open Windows PowerShell.
  2. Paste the line and press Enter.
  3. Restart Claude Code. The set is there, and Claude loads each skill when its moment comes.

Questions

Before you install.

What is a skill?

A written method for one kind of work: when to use it, what it covers, what it hands on, and the checks that prove it is done. Every skill page also says what it is not for, and which skill takes over.

Does it cost anything?

No. You can use it at no cost: no fee, no subscription, no key and no sign-up. The Stryx Labs License v1.1 allows personal and commercial use.

Which systems does it run on?

Windows today. It runs on your own machine.

Can I install one skill on its own?

No. The command installs all 94 skills, 32 agents and the brain program as one set. The books only make the tree together.

Where is the source?

Not in this repository. It holds the project page and the issue tracker only. The set installs from skills.stryxlabs.com, and its licence does not allow posting it on GitHub.

Where do I report a bug or ask for a feature?

Open an issue in this repository with the bug form or the feature form. Take keys and passwords out of any log before you paste it.
